That rootMargin collapses the viewport to a thin band across its middle, so “current” means what is at eye level rather than what merely happens to be on screen. The index pinned to the top of this page is one. The index is only links to the eight legs, grouped: scroll-target-group makes the browser keep track of which target you have reached, and the timetable styles itself from that, with no observer and no script. The links still work as links. Fogg believed he had come home a day late; travelling east, he had seen eighty sunrises while London saw seventy-nine, and he had won.

How it is built.plan ol { scroll-target-group: auto } /* its links become markers for the sections */ .plan a:target-current { color: var(--ink) } /* the leg you are on */ .plan a:target-before::before { content: '✓' } /* the legs behind you */ .plan a:target-after { opacity: .45 } /* the legs ahead */
